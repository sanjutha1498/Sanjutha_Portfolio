Problem

Build a responsive and distraction-free HMI that delivers real-time riding data, navigation, and vehicle controls while operating within embedded hardware constraints and automotive safety standards.

Design approach

Modular, rider-focused HMI system prioritizing glanceability and safety. Clear layouts, large visual elements, and quick-access navigation patterns. Each screen optimized for real-time responsiveness using Kanzi — authentication, dashboard, charging, navigation, personalization and connectivity all reachable within 1–2 taps.

Architecture

Layered system integrating vehicle signals with the Android application layer and Kanzi rendering engine. The exported .kzb bundle acts as a dedicated presentation layer with dynamic property bindings — maintaining a clean separation between business logic and visual rendering, ensuring scalability within an embedded automotive environment.

Collaboration

Worked closely with firmware, embedded, and vehicle engineering teams to ensure seamless system integration and production readiness across multiple OTA releases.
